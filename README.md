# Urban-MicroGrid — 백엔드

**미기후 융합 지역 전력수요·피크 위험 예측** · Watt the hell (2조) / 코디세이 Term-Project

법정동 단위로 전력수요를 예측하고, 동별 상대 임계를 넘으면 피크 경보를 내는 서비스의 백엔드입니다.
공간(토지피복) 대리변수를 기온과 곱한 상호작용항으로 넣어 "동네마다 다른 냉방 반응"을 잡습니다.

---

## 빠른 실행

```bash
pip install fastapi "uvicorn[standard]" pydantic
uvicorn urban_microgrid.api.main:app --reload --port 8000
```

| 주소 | 내용 |
|---|---|
| http://localhost:8000/docs | Swagger UI — **프론트엔드는 이 링크만 있으면 됩니다** |
| http://localhost:8000/api/meta | 지금 서버가 무엇으로 답하고 있는지 |

원자료·pandas 없이도 뜹니다. `docs/api_sample/` 의 실측 산출물을 서빙하는 `snapshot` 모드로 시작하고,
원자료를 넣으면 자동으로 `live` 모드(파이프라인 실행)로 바뀝니다.

계약 회귀 테스트:

```bash
python tests/test_api.py
```

## API 6개

대시보드 화면 하나에 API 하나씩 대응합니다.

| 메서드 | 경로 | 화면 |
|---|---|---|
| GET | `/api/dongs` | 미니맵 핀 |
| GET | `/api/dongs/geojson` | 지도 폴리곤 (GeoJSON FeatureCollection) |
| GET | `/api/dong/{code}` | 우측 지역 카드 |
| GET | `/api/dong/{code}/forecast?date=` | 시계열 차트 · 시간 슬라이더 · 헤더 기상 칩 |
| GET | `/api/compare?codes=A,B` | 지역 비교 |
| GET | `/api/meta` | 데이터 정보 · 출처 표기 |

조회는 10자리 법정동코드로만 합니다 — 진관동 `1138011400`, 구로동 `1153010100`.

**프론트엔드는 계산하지 않습니다.** 등급·색상·문구까지 백엔드가 만들어 내려보냅니다.
값이 없으면 `null` + `status: "pending"` + `note` 를 함께 보내므로, 화면은 스켈레톤과 사유를 띄우면 됩니다.

자세한 계약: [docs/02_지표언어_API계약.md](docs/02_지표언어_API계약.md) ·
실행 가이드: [docs/05_백엔드_실행가이드.md](docs/05_백엔드_실행가이드.md)

## 구조

```
urban_microgrid/
├── config.py       모든 경로·상수·수식 파라미터 (값 변경은 여기서만)
├── io_loaders.py   원자료 적재 — 형식 차이를 전부 흡수
├── features.py     피복률·MCI·ΔT·기저수요·정규화 R
├── models.py       전환온도·민감도·상호작용·예측
├── evaluate.py     성능지표·경보·통계검정
├── landcover.py    토지피복 GIS (순수 파이썬 + geopandas 두 경로)
├── serialize.py    프론트엔드 JSON 직렬화 (등급·색상·문구)
├── run_demo.py     전체 파이프라인
└── api/            FastAPI 백엔드
```

작업을 이어받는다면 [CLAUDE.md](CLAUDE.md) 를 먼저 읽어주세요. 설계 규칙과 데이터 함정이 정리돼 있습니다.

## 결과 (2022-06-28 ~ 08-31)

| 지역 | 도시열 지수 | 평균 R | T* | β | 야간 R | 주간 R |
|---|---|---|---|---|---|---|
| 진관동 | 36.9 (낮음) | 33.1% | 18.0℃ | 2.77 %p/℃ | 31.2% | 34.7% |
| 구로동 | 81.5 (매우 높음) | 27.6% | 19.0℃ | 2.76 %p/℃ | 17.8% | 35.8% |

일평균 R 차이(구로동 − 진관동) = **−5.37 %p** (95% CI [−8.65, −2.08], n=45일, p=0.0026)

냉방 민감도 β 는 두 지역이 사실상 동일했고, 차이는 **야간 수요 패턴**에서 나타났습니다.
방향이 가설과 반대이며, 미기후보다 건물 용도·재실 패턴이 지배적일 가능성이 큽니다.
→ 비교지역을 주거 우세 동으로 조정하고 생활인구를 통제변수로 추가하는 것이 다음 과제입니다.

> **모든 수치는 [프로젝트 예비값]이며 공식 통계가 아닙니다. 2개 동 사례이므로 일반화는 향후 과제입니다.**
> 토지피복 값은 생활권 100m 버퍼 기준이며 법정동 경계 클리핑 전입니다.
