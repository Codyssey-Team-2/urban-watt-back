# 프론트엔드 연동 점검

`urban-watt-front-develop` 목업과 현재 백엔드 계약을 대조한 결과다.

## 즉시 교체할 목 데이터

- 진관동 코드 `1138010600` → `1138011400`
- 창신동 `1111017200` → 구로동 `1153010100`
- 시연일 `2023-08-05` → API `meta.period`과 `forecast.date` 사용
- 창신동 피복률 83.0/13.1, 냉방 기울기 1.8배, MAPE 14.8/10.3/7.1은
  실측 결과가 아닌 목 수치이므로 표시하지 않는다.

## 화면별 백엔드 연결

| 화면 | API | 현재 상태 |
|---|---|---|
| 지도·미니맵 | `/api/dongs`, `/api/dongs/geojson` | 경계 GeoJSON 없으면 `pending` |
| 지역 카드 | `/api/dong/{code}` | 실측 요약과 피복 예비값 제공 |
| 수요·기상 차트 | `/api/dong/{code}/forecast` | ASOS·실측 전력 제공; S-DoT 곡선은 미확보 |
| 지역 비교 | `/api/compare` | 정규화 지표 R로 제공 |
| AI 브리핑 | `/api/briefing` | 키 없으면 `pending` |
| 모델 성능 | `/api/model-performance` | Ablation 전이므로 수치 `null` + `pending` |
| 데모 단서 | `/api/meta` | 미확보 항목과 2개 동 한계 제공 |

## 프론트 연동 시 주의

- 백엔드의 `grade`, `color`, `message`를 그대로 쓴다.
- `pending` 응답은 목 값으로 대체하지 말고 `note`를 표시한다.
- 백엔드 수요 단위는 kWh다. 프론트에서 근거 없이 MW로 바꾸지 않는다.
- 냉방 민감도는 `%p/℃`다. 목업의 `배수` 표현으로 변환하지 않는다.
- B/C 토글의 S-DoT·미기후 모델은 설치위치 매핑과 Ablation 완료 전까지
  `pending`으로 보여준다.
