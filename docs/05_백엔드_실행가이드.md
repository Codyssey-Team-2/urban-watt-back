## 실행

```bash
pip install fastapi "uvicorn[standard]" pydantic
uvicorn urban_microgrid.api.main:app --reload --port 8000
```

| 주소 | 내용 |
|---|---|
| http://localhost:8000/docs | Swagger UI (프론트에 이 링크만 주면 된다) |
| http://localhost:8000/api/meta | **지금 서버가 무엇으로 답하고 있는지** |

계약 회귀 테스트:

```bash
python tests/test_api.py
```

## 두 가지 모드

서버는 기동할 때 원자료 유무를 보고 스스로 모드를 정한다.

| 모드 | 조건 | 동작 |
|---|---|---|
| `snapshot` | 원자료 없음 (기본) | `docs/api_sample/` 의 **실측 산출물**을 서빙. pandas 없이도 뜬다 |
| `live` | 전력 CSV·XLSX + ASOS 가 있고 pandas 설치됨 | `run_demo` 와 같은 함수로 파이프라인을 돌려 응답 생성 |

두 모드 모두 응답 조립은 `serialize.build_*` 하나만 쓴다.
등급·색상·문구가 모드마다 달라지는 사고가 구조적으로 불가능하다.

원자료 위치는 `config.DATA_DIR` 이고, 환경변수로 덮을 수 있다.

```bash
UMG_DATA_DIR=~/urban-data uvicorn urban_microgrid.api.main:app
```

발표 노트북에 원자료를 못 올려도 시연은 그대로 된다.
다만 `snapshot` 모드에서는 시계열이 **진관동 2022-07-10 하루**만 있다.

## 엔드포인트

| 메서드 | 경로 | 비고 |
|---|---|---|
| GET | `/api/dongs` | 미니맵 핀. 미확보 동도 색(`#9E9E9E`)이 온다 |
| GET | `/api/dongs/geojson` | 지도 폴리곤. 채움색까지 실려 나온다 |
| GET | `/api/dong/{code}` | 동 상세 카드 |
| GET | `/api/dong/{code}/forecast?date=YYYY-MM-DD` | 기본값은 시연 기준일(2022-07-10) |
| GET | `/api/compare?codes=A,B` | 요청한 코드 순서를 지킨다 |
| GET | `/api/model-performance` | Ablation 성능. 미측정 시 200 + `pending` |
| GET | `/api/briefing?codes=A,B` | AI 브리핑 (Gemini). 키가 없으면 `pending` |
| GET | `/api/meta` | 모드 · 미확보 항목 · 발표 단서 |

엔드포인트 목록은 `tests/test_api.py::test_endpoint_inventory` 가 고정한다.
화면에 대응하지 않는 API 는 만들지 않는다 — 경보 목록(`/api/alerts`)은 목업에
해당 패널이 없어 제거했다. 되살리려면 `serialize.build_alerts` 가 그대로 남아 있다.

조회는 **10자리 법정동코드로만** 한다. 진관동 `1138011400`, 구로동 `1153010100`.

## 상태 코드

| 코드 | 언제 | 응답 |
|---|---|---|
| 200 | 정상 | 계약대로 |
| 404 | 분석 대상이 아닌 동 코드 | `{"status":"not_found","detail":…,"note":"분석 대상: …"}` |
| 503 | 요청은 맞지만 **자료가 아직 없음** | `{"status":"pending","detail":…,"note":…}` |

미확보 자료를 500 으로 떨어뜨리지 않는다. 프론트는 `note` 를 스켈레톤에 그대로 띄운다.

## 미기후(ISR/VCR) 블록 ★

`microclimate.status` 는 **두 동 모두 `ready`** 다. 값의 출처는 `docs/06` 이다.

| | 구로동 | 진관동 |
|---|---|---|
| 불투수 / 식생 | 78.8% / 15.9% | 31.2% / 57.4% |
| 도시열 지수 | 81.5 (매우 높음) | 36.9 (낮음) |

값은 `config.MICROCLIMATE_PRELIM`, 산출 기준은 `config.MICROCLIMATE_BASIS` 에 있다.
**코드에는 숫자가 없다.**

### 응답이 값과 함께 보내는 것

```json
"note":   "[프로젝트 예비값] 생활권 100m 버퍼 기준 · 도엽 병합 범위(법정동 경계 클리핑 전)",
"caveat": "나지·습지는 불투수·식생 어디에도 포함하지 않으므로 세 비율의 합은 100%가 아닙니다",
"basis":  { "tag": "프로젝트 예비값", "clipped_to_dong": false, ... }
```

`status: "ready"` 여도 `note` 를 비우지 않는다. **예비값이 확정값처럼 보이면 안 되기 때문**이다.
프론트는 카드 하단에 `note`, 도넛 옆에 `caveat` 를 그대로 출력한다.

법정동 경계 SHP 을 확보해 `landcover.coverage_for_dong()` 을 돌린 뒤:

```python
MICROCLIMATE_PRELIM = {"1138011400": {"ISR": ..., "VCR": ..., "WSR": ...}}
MICROCLIMATE_BASIS  = {..., "clipped_to_dong": True, "note": "..."}
```

두 줄만 바꾸면 전 화면 문구가 자동으로 바뀐다.

`tests/test_api.py` 가 지키는 것
- `test_microclimate_matches_config` — 산출값이 화면까지 그대로 도달하는지, 도시열 지수 계산이 맞는지
- `test_prelim_tag_reaches_the_screen` — '예비값' 단서가 응답에서 사라지지 않는지
- `test_cover_percentages_do_not_sum_to_100` — 합을 100 으로 맞추려는 손질 방지
- `test_no_unmeasured_microclimate` — 도엽 전체값(5.37)·창신동 값(83.0/13.1) 혼입 방지

## 지도 폴리곤 붙이기

경계 파일이 없으면 `/api/dongs/geojson` 은 `503 pending` 으로 답한다.
프론트는 폴리곤 레이어를 건너뛰고 `/api/dongs` 핀만 찍으면 되므로 지도가 비지 않는다.

경계 SHP 을 받으면:

```bash
python -m urban_microgrid.landcover 법정동경계.shp
```

- `data/dong_boundaries.geojson` 이 생성된다 (EPSG:4326 변환 · 단순화 · 좌표 6자리)
- 코드 컬럼(`EMD_CD` · `ADM_CD` · `adm_cd` …)은 **자동 탐색**한다
- 서버 재시작하면 폴리곤이 나간다

이미 GeoJSON 을 갖고 있다면 변환 없이 `data/dong_boundaries.geojson` 으로 두면 된다.
탐색 경로는 `config.BOUNDARY_GEOJSON_CANDIDATES`, 스타일은 `config.MAP_STYLE` 이다.

`geopandas` 는 **변환할 때만** 필요하다. 서버는 GeoJSON 만 읽으므로 의존성이 없다.

## AI 브리핑 (LLM)

목업 우측 레일의 "AI 브리핑" 패널. **모델은 분석하지 않는다.**
백엔드가 실측값으로 사실표를 만들고, 모델은 그것을 문장으로 옮기기만 한다.

```
serialize (실측 산출물)
   → briefing.build_facts   사실표 — 브리핑에 등장할 수 있는 유일한 숫자
   → briefing.build_prompt  사실표 + 표현 규칙
   → llm.generate           Gemini 호출
   → briefing.verify        사실표에 없는 숫자 검출
```

### 켜는 법

```bash
pip install google-genai
export GEMINI_API_KEY=...        # https://aistudio.google.com/apikey
```

키가 없으면 `503` + `status:"pending"` 이고, 프론트는 스켈레톤을 띄우면 된다.
지금 켜져 있는지는 `GET /api/meta` 의 `llm.status` 로 확인한다.

### 응답에 프롬프트가 들어 있다

```json
{
  "status": "ready",
  "text": "…",
  "prompt": { "system": "…", "user": "…" },
  "facts":  { … },
  "unverified_numbers": []
}
```

코드를 열지 않고 프롬프트를 검토·튜닝할 수 있게 그대로 노출한다.
문구를 바꾸려면 `config.BRIEFING_RULES` 만 고친다.

### 지어낸 숫자 방어 ★

LLM 은 그럴듯한 수치를 만들어낸다. 이 프로젝트에서 그건 규칙 5 위반이다.
`briefing.verify()` 가 생성된 문장의 모든 숫자를 사실표와 대조해,
없는 숫자를 `unverified_numbers` 로 돌려준다.

- 비어 있으면 `status: "ready"`
- 하나라도 있으면 `status: "needs_review"` + `note` → **화면에 경고를 띄운다**

`tests/test_api.py::test_briefing_verifier_catches_invented_numbers` 가
docs/04 §7-1 이 지적한 미측정 성능 수치(14.3 / 6.2)를 잡는지 확인한다.

통과했다고 문장이 참인 것은 아니다. '수치 조작'이라는 가장 큰 사고를 막는 장치다.

### 캐시

같은 `codes` + `date` 는 다시 호출하지 않는다. 시연 중 새로고침할 때마다
문구가 바뀌면 안 되고 비용도 계속 나가면 안 된다. 강제로 새로 만들려면 `?refresh=true`.

### 모델 교체

`urban_microgrid/llm.py` 의 `_ADAPTERS` 에 함수 하나를 추가하고
`UMG_LLM_PROVIDER` 로 고른다. 사실표·프롬프트·검증은 그대로 쓴다.

```bash
UMG_LLM_MODEL=gemini-3.6-flash uvicorn urban_microgrid.api.main:app
```

## 프론트엔드 연동 메모

- 프론트는 **등급·색상·문구를 계산하지 않는다.** 받은 값을 그대로 쓴다.
- `microclimate.status === "pending"` → 스켈레톤 + `note` 표시
- 차트: `usage_kwh` 실선 · `baseline_kwh` 점선 · `threshold_kwh` 가로선 · 포인트 색은 `color`
- 지도: `/api/dongs/geojson` 의 `features` 를 그대로 넣고 `properties.fill_color` 로 칠한다
- 헤더 기상 칩: `forecast.weather` (`humidity`·`wind` 가 `null` 이면 칩을 숨긴다)
- AI 브리핑: `briefing.text` 를 그대로 출력. `unverified_numbers` 가 있으면 경고 배지
- 모델 성능: `/api/model-performance`. `status === "pending"`이면 임의 MAPE 대신 `note` 표시
- 시각은 KST 고정, 타임존 오프셋이 없는 ISO 문자열이다 (`2022-07-10T13:00:00`)
- CORS 는 데모용으로 전체 허용(`config.API_CORS_ORIGINS`). 배포 시 프론트 도메인만 남긴다

## 파일

```
urban_microgrid/api/
├── schemas.py   계약을 pydantic 타입으로 고정 — 계약 위반 응답은 여기서 터진다
├── store.py     데이터 원천 (live / snapshot) · 기동 시 1회 적재
├── routes.py    엔드포인트 8개
└── main.py      앱 조립 · CORS · 예외 → 상태코드 번역
```

새 상수는 코드가 아니라 `config.py` 에 넣는다.
등급 문구·색상은 `serialize.HEAT_GRADES` / `RISK_GRADES` 에서만 관리한다.
